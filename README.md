# 🔗 LinkedIn Authentication UI Clone

A responsive front-end clone of LinkedIn's authentication pages built using **HTML** and **CSS**. This project recreates the Sign In, Login, and Reset Password interfaces with a clean and modern UI inspired by LinkedIn.

---

## 📌 Features

- ✅ LinkedIn-inspired Sign In page
- ✅ Login page
- ✅ Forgot / Reset Password page
- ✅ Responsive UI Design
- ✅ Google Sign-In Button Integration (UI)
- ✅ Modern Layout
- ✅ Clean HTML & CSS Structure
